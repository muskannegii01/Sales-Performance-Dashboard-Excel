# Sales Performance Dashboard | Microsoft Excel

## Project Overview
This project focuses on analyzing sales performance and creating an interactive dashboard using Microsoft Excel. The dashboard helps monitor sales, profit, product performance, and regional trends.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Slicers

## Key Performance Indicators (KPIs)
- Total Products
- Total Sales
- Average Order Value
- Total Profit
- Total Profit Margin
- Loss Products Count

## Dashboard Features
- Sales by Category
- Top 5 Products
- Sales by Region
- Loss-Making Products
- Monthly Sales Trends
- Interactive filters for Region, Year, and Month

## Key Analysis
The dashboard provides insights into product performance, category-wise sales, regional sales distribution, monthly trends, and loss-making products.

## Project Files
- Excel workbook containing the dashboard and data.
- Dashboard screenshot for a quick preview.

## Conclusion
This project demonstrates the use of Microsoft Excel for sales analysis, interactive reporting, and business performance monitoring.
